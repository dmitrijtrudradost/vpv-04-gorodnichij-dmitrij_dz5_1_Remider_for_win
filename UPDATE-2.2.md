# Обновление Напоминалки 2.1 → 2.2 на уже установленном компьютере

Эта инструкция для удалённого или чужого Windows-компьютера, где **уже работает версия 2.1**.
Git и Node.js не нужны. База напоминаний и процессы сохраняются.

## Что даст 2.2

- «Отложить» на любую дату и время, не только на 5 минут; кнопки +45 мин и +1 час
- Конструктор процессов: свои шаблоны (ветки, шаги, связи, чек-листы, эскалация)
- Встроенные «ЭДО-договор» и «Охрана объекта» по-прежнему только для запуска, не для правки
- Копирование в полях (Ctrl+C / Ctrl+V)
- Кнопка «Показать/Скрыть данные договора охраны»

## Что нельзя трогать

Файл **`reminders.db`** — это все напоминания и процессы. Его не удалять и не заменять файлом из архива (в архиве базы нет, но при копировании папок целиком её легко затереть своей пустой копией).

## 1. Полностью выйти из программы

Крестик окна только сворачивает в трей. Нужен полный выход:

1. Найти иконку «Напоминалка» в трее (возле часов).
2. Правый клик → **Выход**.

Проверка: иконки в трее больше нет, в диспетчере задач нет `python.exe` / `pythonw.exe` с «Напоминалкой».

## 2. Сделать копию базы

Найдите папку, откуда запускается 2.1 (часто `C:\napominalka` или рядом с ярлыком).
Скопируйте `reminders.db` на рабочий стол или на флешку, например:

```text
reminders.db.bak-2.1
```

## 3. Скачать архив 2.2

Возьмите `napominalka-2.2-win.zip` из [релиза 2.2 на GitHub](https://github.com/dmitrijtrudradost/vpv-04-gorodnichij-dmitrij_dz5_1_Remider_for_win/releases/tag/2.2).

Распакуйте во **временную** папку, например `C:\napominalka-2.2-new`.

## 4. Подменить файлы, не трогая базу

В папке текущей установки замените файлы из архива. Удобный способ:

1. Скопируйте из распакованного архива **всё, кроме** того, чего нет в архиве как данных пользователя.
2. Вставьте в папку 2.1 с заменой файлов.
3. Убедитесь, что `reminders.db` на месте и не исчез.

Должны появиться или обновиться как минимум:

| Путь | Зачем |
| --- | --- |
| `main.py`, `database.py`, `gui.py`, `notifications.py`, `templates.py`, `autostart.py` | Новая логика 2.2 |
| `process_builder.py` | Окно конструктора |
| `process_builder_web\dist\` | Готовый интерфейс конструктора |
| `requirements.txt` | Новая зависимость `pywebview` |
| `README.md`, `INSTALL.md`, `UPDATE-2.2.md` | Документация |

Папку `process_builder_web\src` можно копировать, но для запуска достаточно `dist`.
**Node.js ставить не нужно.**

## 5. Обновить Python-зависимости

В PowerShell, в папке установки:

```powershell
cd C:\Program Files (x86)\Napominalka
pip install -r requirements.txt
```

Подставьте свой путь вместо `C:\napominalka`.
Должен установиться пакет `pywebview`. Если программа крутится в виртуальном окружении `.venv`, сначала активируйте его, затем ту же команду.

## 6. Запустить и проверить

```powershell
python main.py
```

Проверьте:

1. В заголовке окна — **Напоминалка 2.2**.
2. Старые напоминания и процессы на месте.
3. На вкладке «Процессы» есть кнопка **Конструктор процессов** — окно открывается.
4. Для шаблона «Охрана объекта» кнопка **Показать/Скрыть данные договора охраны** открывает поля; даты вида `21.12.2026` принимаются.
5. Уведомление можно отложить на выбранную дату, не только на 5 минут.

Если конструктор пишет, что не открывается: установите [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (на большинстве Windows 10/11 с Edge он уже есть) и снова `pip install -r requirements.txt`.

## 7. Автозапуск

Если программа стартовала при входе в Windows, ничего менять не обязательно: ярлык по-прежнему вызывает тот же `main.py`.

Если после обновления автозапуск пропал: трей → **Не запускать при входе**, затем снова **Запускать при входе в Windows**.

## Если что-то пошло не так

1. Снова **Выход** из трея.
2. Верните сохранённый `reminders.db.bak-2.1` на место `reminders.db`.
3. При необходимости верните файлы 2.1 из старого архива.

Первый запуск 2.2 сам добавит в базу таблицу `process_templates`. Ручных SQL-скриптов нет.
