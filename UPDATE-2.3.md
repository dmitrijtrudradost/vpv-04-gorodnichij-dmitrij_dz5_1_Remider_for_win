# Обновление Напоминалки 2.2 → 2.3 на уже установленном компьютере

Эта инструкция для удалённого или чужого Windows-компьютера, где **уже работает версия 2.2**.
Git и Node.js не нужны. База напоминаний и процессы сохраняются. Схема базы
обновится сама при первом запуске 2.3.

## Что даст 2.3

- Выбор нескольких напоминаний щелчками и удаление выбранных одним подтверждением
- Записи «Готово» старше суток удаляются автоматически
- У чек-листа и эскалации в конструкторе — дата «Действует с»
- Эскалация из произвольного числа шагов «Через» / «В время»; её можно включить у любого незакрытого шага
- Галочка «Уведомлять в выходные»
- Переименование шага щелчком по названию на холсте конструктора
- Кнопки «Просроченные» и «Возобновить»: только выбранные просроченные, только вручную

## Что нельзя трогать

Файл **`reminders.db`** — это все напоминания и процессы. Его не удалять и не заменять файлом из архива (в архиве базы нет, но при копировании папок целиком её легко затереть своей пустой копией).

После обновления записи со статусом «Готово» получат отметку времени и будут
удалены через сутки. «Отменено» и «Просрочено» не трогаются.

## 1. Полностью выйти из программы

Крестик окна только сворачивает в трей. Нужен полный выход:

1. Найти иконку «Напоминалка» в трее (возле часов).
2. Правый клик → **Выход**.

Проверка: иконки в трее больше нет, в диспетчере задач нет `python.exe` / `pythonw.exe` с «Напоминалкой».

## 2. Сделать копию базы

Найдите папку, откуда запускается 2.2 (часто `C:\napominalka` или рядом с ярлыком).
Скопируйте `reminders.db` на рабочий стол или на флешку, например:

```text
reminders.db.bak-2.2
```

## 3. Скачать архив 2.3

Возьмите `napominalka-2.3-win.zip` из релиза 2.3.

Распакуйте во **временную** папку, например `C:\napominalka-2.3-new`.

## 4. Подменить файлы, не трогая базу

В папке текущей установки замените файлы из архива. Удобный способ:

1. Скопируйте из распакованного архива **всё, кроме** того, чего нет в архиве как данных пользователя.
2. Вставьте в папку 2.2 с заменой файлов.
3. Убедитесь, что `reminders.db` на месте и не исчез.

Должны появиться или обновиться как минимум:

| Путь | Зачем |
| --- | --- |
| `main.py`, `database.py`, `gui.py`, `notifications.py`, `templates.py`, `autostart.py` | Новая логика 2.3 |
| `process_builder.py` | Окно конструктора |
| `process_builder_web\dist\` | Готовый интерфейс конструктора |
| `README.md`, `INSTALL.md`, `UPDATE-2.3.md` | Документация |

Папку `process_builder_web\src` можно копировать, но для запуска достаточно `dist`.
**Node.js ставить не нужно.** Новых Python-пакетов в 2.3 нет.

## 5. Запустить и проверить

```powershell
python main.py
```

Проверьте:

1. В заголовке окна — **Напоминалка 2.3**.
2. Старые напоминания, процессы и пользовательские шаблоны на месте.
3. В списке можно выбрать несколько строк щелчками и удалить их одной кнопкой.
4. Кнопки **Просроченные** и **Возобновить** есть на панели над списком.
5. Конструктор открывает встроенный шаблон (только просмотр) и сохранённый в 2.2 пользовательский шаблон.
6. У шага в конструкторе есть «Действует с», список шагов эскалации и галочка выходных.

Если конструктор пишет, что не открывается: установите [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (на большинстве Windows 10/11 с Edge он уже есть) и снова `pip install -r requirements.txt`.

## 6. Автозапуск

Если программа стартовала при входе в Windows, ничего менять не обязательно: ярлык по-прежнему вызывает тот же `main.py`.

Если после обновления автозапуск пропал: трей → **Не запускать при входе**, затем снова **Запускать при входе в Windows**.

## Если что-то пошло не так

1. Снова **Выход** из трея.
2. Верните сохранённый `reminders.db.bak-2.2` на место `reminders.db`.
3. При необходимости верните файлы 2.2 из старого архива.

Первый запуск 2.3 сам добавит в базу колонку `completed_at` и поля шага
`checklist_active_from`, `escalation_active_from`, `notify_weekends`.
Ручных SQL-скриптов нет.
